# leetschool

## Гайд как начать работу с репозиторием
1. Нужно установить зависимости (чуть позже узнаете, что это) командой `npm install`. Пока что просто тупо устанавливаете и все
2. Запустить проект командой `npm run dev`, запустится по ссылке http://localhost:5173/
3. Далее создать свою ветку с номером задачи, перейти в нее и начать работать. Пример названия ветки - `wayleet/practice22`
4. Все изменения автоматически применятся после сохранения и вы сразу можете их увидеть на `localhost`
3. Как задача будет готова пушите изменения в удаленный репозиторий и кидаете ссылку на pull request в чат

Важный пункт: когда сдадите задачу и перейдете к другой, обновите ветку `master` до последней версии. 
Это можно сделать через UI в webstorm или находясь в ветке `master` командой `git pull`
